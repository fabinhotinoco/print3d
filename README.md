# print3d

Peças para impressão 3D (Bambu Lab A1 e A2L) modeladas por código.

    pip install -r requirements.txt
    python projects/000-teste-folgas/model.py   # gera out/ com STEP, STL, 3MF e prévia

Abra o `.3mf` de `out/` no BambuStudio, fatie e imprima.

## Atalho na Mesa (Mac)

Uma vez só, depois de clonar:

    bash ~/print3d/tools/instalar-atalho.sh

Cria a pasta **Impressão 3D** na Mesa com todos os `.3mf` prontos (e as prévias `.png`).
Para receber peças novas: duplo clique em **↻ Atualizar** dentro dela.
